# Contributing to PFO OS

## Purpose

This repository follows enterprise engineering practices.

Every contribution should improve maintainability, documentation or functionality.

---

# Before Starting

Read:

- START_HERE.md
- .ai/AI_CONTEXT.md
- .ai/AI_CONTRACT.md
- .ai/CURRENT_SPRINT.md

---

# Branching

Use GitHub Flow.

```
main
feature/<feature-name>
```

---

# Commit Messages

Follow Conventional Commits.

Examples:

```
feat(core):
docs(ai):
fix(report):
refactor(domain):
test(analytics):
chore(repo):
```

---

# Pull Requests

Every pull request should include:

- Summary
- Scope
- Testing
- Risks
- Future Work

---

# Coding Standards

- Production quality
- TypeScript
- SOLID
- DDD
- Clean Architecture

---

# Documentation Standards

Every major change should update relevant documentation.

---

# AI Contributions

AI-generated content must:

- Be reviewed.
- Follow repository standards.
- Avoid assumptions.
- Preserve repository consistency.

---

# Definition of Done

A task is complete when:

- Implementation is complete.
- Documentation is updated.
- Repository state is updated.
- No placeholder content remains.
