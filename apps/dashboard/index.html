INVESTOR-PERSPECTIVE CASH FLOWS

Investment performance calculator

Local calculation · INR

Enter dated contributions as negative amounts and receipts as positive amounts. Include an explicit positive terminal valuation on the date you want to measure performance if the investment is still held. No market value is fetched or inferred.

!
Use the local workspace for investment calculations

Run pnpm dashboard:serve locally before entering personal investment cash flows.

Dated cash flows

All amounts use INR. Same-date flows are netted for XIRR. Streams with ambiguous multiple sign changes are rejected.

CSV import format: date,amount. Use ISO dates and signed INR amounts (negative contributions, positive receipts); importing replaces the entered cash flows after confirmation.

The annualized return uses the existing ACT/365 XIRR solver. Gross contributions, proceeds, and simple net return are descriptive arithmetic. Taxes, fees, inflation, currency conversion, and investment recommendations are excluded.

HISTORICAL RETURN SERIES

Return risk analysis

Local calculation · no forecasts

Paste one observation per line as YYYY-MM-DD,return-percent, oldest first. A date,return_percent header is also accepted. Returns are simple period returns, not currency amounts. Use consistent observation intervals and choose the annualization frequency that matches them.

!
Use the local workspace for return analysis

Run pnpm dashboard:serve locally before entering personal investment data.

Metrics are descriptive and depend on the supplied observations. Volatility uses sample standard deviation annualized by √periods/year; drawdown uses a compounded wealth index. Sharpe and Sortino require explicit assumptions. No market data is fetched, and no risk score or investment recommendation is produced. Inputs are not saved.
