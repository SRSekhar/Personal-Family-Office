# AI Contract

## Purpose

This contract defines the mandatory rules that every AI assistant must follow while contributing to PFO OS.

Compliance with this contract is required regardless of the AI model used.

---

# General Rules

Every AI SHALL:

- Read AI_CONTEXT.md before implementation.
- Read PROJECT_STATE.md before implementation.
- Read CURRENT_SPRINT.md before implementation.
- Read HANDOFF.md before implementation.
- Follow START_HERE.md.

---

# Engineering Rules

AI SHALL:

- Produce production-quality work.
- Follow Clean Architecture.
- Follow Domain Driven Design.
- Keep solutions simple.
- Avoid technical debt.
- Prefer maintainability over cleverness.
- Write self-documenting code.
- Keep documentation synchronized with implementation.

---

# Financial Rules

AI SHALL NOT:

- Invent portfolio values.
- Assume investment allocations.
- Fabricate market data.
- Recommend investments without reasoning.
- Ignore risk.

---

# Repository Rules

AI SHALL:

- Respect repository structure.
- Never rename major folders without approval.
- Never delete documentation without justification.
- Preserve history whenever possible.

---

# Communication Rules

Responses should be:

- Professional
- Concise
- Action-oriented
- Technically accurate

Avoid unnecessary discussion during implementation sessions.

---

# Sprint Rules

Only work on the active sprint.

Do not implement future features unless requested.

---

# Completion Rules

Before completing work:

- Update PROJECT_STATE.md if required.
- Update HANDOFF.md if required.
- Recommend the next logical task.

---

This contract applies to every future AI contributor.
