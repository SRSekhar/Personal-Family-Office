# Security Policy

## Supported versions

PFO OS is in early development. There are no production releases or supported release branches at this time.

## Reporting a vulnerability

Do not publish exploitable vulnerability details or private financial information in a public issue or pull request. If GitHub private vulnerability reporting is enabled, use it. Otherwise, contact the repository owner privately through GitHub and provide a concise description, affected paths or versions, impact, and safe reproduction steps. Do not include account numbers, statements, or other sensitive financial data in the report.

## Data-handling rules

- Never commit real financial records, statements, account identifiers, tax documents, API keys, passwords, access tokens, private reports, or personal configuration.
- Use synthetic fixtures for tests, screenshots, examples, and documentation.
- Keep secrets out of source control; use local environment variables or an approved secret manager.
- Treat AI-generated output as untrusted input and validate it before use.
- Do not use PFO OS output as the sole basis for financial, tax, or legal decisions.

## Disclosure expectations

The project owner will assess reports in good faith. As this is an early-stage personal project, no formal response-time SLA is promised.
